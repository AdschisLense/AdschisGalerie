# Anweisungen für Agenten

Diese Regeln gelten für das gesamte Repository einschließlich aller Unterordner.

## Git

Die Verwendung von Git ist ausdrücklich erlaubt. Dazu gehören insbesondere
Statusabfragen, Diffs, Branches, Staging, Commits, Fetch, Pull und Push im Rahmen
des jeweiligen Benutzerauftrags. Übergeordnete Sicherheits- und
Berechtigungsvorgaben bleiben gültig.

## Keine Tests erstellen

Das Erstellen, Generieren oder Hinzufügen von Tests ist ausdrücklich verboten.
Dies umfasst insbesondere Unit-, Integrations-, End-to-End- und Regressionstests,
Untertests, Testskripte, Testsuiten sowie Testordner und Test-Unterordner.
Es dürfen auch keine temporären Testdateien angelegt werden.
